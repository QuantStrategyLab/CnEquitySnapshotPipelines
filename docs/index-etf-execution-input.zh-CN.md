# 指数 ETF 严格回测输入导入

`cneq-publish-index-etf-input` 把已取得许可的本地 JSON 导出保存为不可变输入包，供 CnEquityStrategies 的严格日线回测读取。它不联网、不补齐缺失行情，也不修改现有行业 ETF / Tencent 采集入口。

输入包括原始成交价 OHLC、以份为单位的成交量、交易日历、当日开盘前已知的停牌与涨跌停状态，以及覆盖整个窗口的分红和拆分事件。分红须含登记日、除权日、到账日及适用净派息。缺字段、缺交易日、重复行或不能证明完整的事件覆盖都应停止。具体字段和时间边界由策略仓的 `load_index_etf_input` 校验，发布端复用该校验，不另定义较宽松格式。

三个源 JSON 的原始字节与规范化成员一并保留；官方许可原文、来源、版本及允许私人保留的范围也进入输入包。源观察时间来自实际导出记录，导入时间不能冒充历史可用时间。不得自行用当前日期、默认交易日历或空事件列表补缺。

发布要求绝对路径、无符号链接、干净且可验证版本的源码，以及仓库外、用户私有、位于两个不同设备的现有保管目录。写入先校验和同步到存储，再原子发布并回读；重复输入复用同一包，已有同名但字节不同的包拒绝覆盖。第二份存储失败不会返回成功；已成功保存的第一份仍保留，可在排除存储故障后用原输入补齐。

默认 `--evidence-kind synthetic`。`historical` 仅表示操作者声明来源属于历史数据，不能自授真实来源或晋级资格。后续 owning job 必须独立核实许可、真实来源和保留范围，再在受控配置绑定同一个 manifest 根；CLI 不提供交易或晋级授权。合成输入始终只能用于测试。

命令的 `--help` 列出必填路径和来源字段。输出只包含发布状态、manifest 根及 `promotion_authority_granted=false`，不输出行情、底层异常或凭据。

离线测试使用合成输入、模拟两设备，并让实际策略 consumer 读取发布结果。这证明字节和调用链契约，不证明免费数据源已覆盖所需历史，也不等于真实回测或 shadow 验证。
